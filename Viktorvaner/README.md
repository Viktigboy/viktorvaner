# Viktorvaner (Android habit tracker)

1. Install Android Studio (Koala or newer) and open this folder.
2. Wait for Gradle sync (downloads Gradle 8.7 + dependencies).
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
   APK: app/build/outputs/apk/debug/app-debug.apk
4. Copy it to your Samsung and install (allow "install unknown apps").

Widget: long-press home screen > Widgets > Viktorvaner. On One UI you can also
add it from Lock screen > Edit > Widgets, where your device offers that.
